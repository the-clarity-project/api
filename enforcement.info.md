# API для Clarity Project

[Опис API](README.md)

### Виконавчі провадження

Дані Автоматизованої системи виконавчого провадження, доповнені інформацією 
з Єдиного реєстру боржників.

Всі методи повертають відповідь в [однаковому форматі](#формат-відповіді).

## enforcement.info
Метод повертає виконавчі провадження за їх номерами.

##### Параметри:
* **order_num** - номер виконавчого провадження або кілька номерів через кому, не більше 25;

##### Приклад запиту:
https://clarity-project.info/api/enforcement.info?order_num=12345678,12345679&key=xxx

Провадження, які не знайдено, у відповідь не потрапляють. 

Метод повертає помилку з кодом **400**, якщо параметр `order_num` відсутній, 
містить щось крім цілих чисел або понад 25 номерів.

## edr.info/enforcements
Метод повертає виконавчі провадження, в яких юридична особа є стягувачем або боржником.

##### Параметри:
* **page** - сторінка результатів, за замовчуванням перша;

##### Приклад запиту:
https://clarity-project.info/api/edr.info/00000000/enforcements?page=1&key=xxx,
де **00000000** - код ЄДРПОУ.

Метод повертає по 25 записів на сторінку, спочатку найновіші за датою відкриття. 

Якщо проваджень немає - список `items` повертається порожнім.

## persons.info/enforcements
Метод повертає виконавчі провадження, в яких фізична особа є стягувачем або боржником.

##### Параметри:
* **page** - сторінка результатів, за замовчуванням перша;

##### Приклад запиту:
https://clarity-project.info/api/persons.info/00000000000000000000000000000000/enforcements?page=1&key=xxx

Де:
* `00000000000000000000000000000000` - це ідентифікатор (`hash`) особи з методу 
  [persons.search](persons.search.md#personssearch), або її ПІБ.

Метод повертає по 25 записів на сторінку, спочатку найновіші за датою відкриття. 

Якщо проваджень немає або особу не знайдено - список `items` порожній.

## Формат відповіді

##### Приклад відповіді:
```json
{
  "result": {
    "items": [
      {
        "order_number": 12345678,
        "date_start": "2023-03-01",
        "state": {
          "state": "enforcement",
          "name": "Примусове виконання"
        },
        "dvs_code": "00000000",
        "creditor": {
          "type": "company",
          "name": "ТОВ \"ПРИКЛАД\"",
          "name_hash": null,
          "edrpou": "00000000",
          "birth_date": null
        },
        "debtor": {
          "type": "person",
          "name": "ПРИКЛАД ПЕТРО ІВАНОВИЧ",
          "name_hash": "00000000000000000000000000000000",
          "edrpou": null,
          "birth_date": "1970-01-15"
        },
        "erb_record": {
          "order_number": 12345678,
          "category": "Стягнення коштів",
          "executor_name": "Приклад Іван Петрович",
          "executor_organization": "Відділ державної виконавчої служби",
          "publisher": "Прикладний районний суд",
          "is_actual": true,
          "updated_at": "2024-02-01 10:20:30"
        },
        "updated_at": "2024-02-01 10:20:30"
      },
      {
        "order_number": 12345679,
        "date_start": "2022-11-20",
        "state": {
          "state": "completed",
          "name": "Завершено"
        },
        "dvs_code": null,
        "creditor": {
          "type": "other",
          "name": "ПРИКЛАДНА МІСЬКА РАДА",
          "name_hash": "11111111111111111111111111111111",
          "edrpou": null,
          "birth_date": null
        },
        "debtor": {
          "type": "company",
          "name": "ТОВ \"ПРИКЛАД\"",
          "name_hash": null,
          "edrpou": "00000000",
          "birth_date": null
        },
        "erb_record": null,
        "updated_at": "2023-06-10 04:05:06"
      }
    ],
    "total": 2,
    "page": 1,
    "perPage": 25,
    "limit": 25,
    "offset": 0
  },
  "stats": { }
}
```

##### Опис полів:
* `items` - список виконавчих проваджень:
  * `order_number` - номер виконавчого провадження;
  * `date_start` - дата відкриття, `null` - якщо відсутня;
  * `state` - стан провадження:
    * `state` - код стану: `opened`, `enforcement`, `suspended`, `completed`, `finished`, `refused`;
    * `name` - назва стану: Відкрито, Примусове виконання, Зупинено, Завершено, Закінчено, 
      Відмовлено у відкритті;
  * `dvs_code` - код ЄДРПОУ органу виконавчої служби, `null` - якщо відсутній;
  * `creditor`, `debtor` - стягувач та боржник:
    * `type` - тип сторони: `company` - юридична особа, `person` - фізична особа, `other` - інше;
    * `name` - назва або ПІБ, `null` - якщо відсутні;
    * `name_hash` - хеш імені, для фізичної особи це ідентифікатор для методу 
      [persons.info](persons.search.md#personsinfo), для юридичної особи `null`;
    * `edrpou` - код ЄДРПОУ, заповнюється лише для юридичних осіб;
    * `birth_date` - дата народження, заповнюється лише для фізичних осіб, `null` - якщо відсутня;
  * `erb_record` - запис у Єдиному реєстрі боржників, `null` - якщо відсутній:
    * `order_number` - номер виконавчого провадження;
    * `category` - категорія стягнення;
    * `executor_name` - виконавець;
    * `executor_organization` - організація виконавця;
    * `publisher` - орган, що видав документ;
    * `is_actual` - `false`, якщо запис видалено з реєстру (архівні дані);
    * `updated_at` - дата актуальності запису;
  * `updated_at` - дата останнього оновлення запису;
* `total` - загальна кількість записів;
* `page` - номер поточної сторінки;
* `perPage`, `limit` - кількість записів на сторінці;
* `offset` - зсув першого запису сторінки;
