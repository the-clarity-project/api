### Обтяження рухомого майна

## drorm.search

Метод повертає скорочені дані обтяжень рухомого майна фізичної або юридичної особи з ДРОРМ.

**⚠ ЗВЕРНІТЬ УВАГУ:** Користувач-власник API-ключа має пройти ідентифікацію [в своєму профілі](https://clarity-project.info/me/identification). Демо-ключі не підтримуються.

##### Приклад запиту:

https://clarity-project.info/api/drorm.search?key=xxx&code=12345678

Параметри пошуку:

- **code** — код ЄДРПОУ юридичної особи або РНОКПП фізичної особи;
- **name** — ПІБ фізичної особи.

Можна шукати юридичну особу за кодом, фізичну особу за кодом або ПІБ. Для фізичної особи також можна передати ПІБ і код разом. Потрібно вказати хоча б один параметр. Пошук за ПІБ може повернути записи різних осіб з однаковим ПІБ.

Для запиту застосовуються загальні ліміти й облік публічного API; кожен успішний виклик списує один запит.

### Формат відповіді

`records` містить список знайдених обтяжень. Якщо результатів немає, повертається порожній список. Відсутні поля запису мають значення `null`.

```json
{
  "records": [
    {
      "opOpID": 123456,
      "opType": null,
      "lmType": null,
      "lmSort": null,
      "regDate": null,
      "properties": null,
      "subjects": null,
      "subjectDbt": null,
      "nameRegister": null,
      "objRegister": null
    }
  ],
  "stats": {
    "query_time": 0.15,
    "quota": { "used": 10, "max": 100, "key_used": 10 }
  }
}
```

`opOpID` — ідентифікатор запису ДРОРМ; решта полів містить скорочену інформацію з результату пошуку.
