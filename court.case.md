### Судові справи та рішення

## court.case
Метод повертає інформацію про судову справу за її номером: стан розгляду, 
призначені засідання, учасників та судові рішення.

##### Параметри:
* **case** - номер справи;
* **page** - сторінка списку рішень, за замовчуванням перша;

##### Приклад запиту:
https://clarity-project.info/api/court.case?case=000/0000/23&page=1&key=xxx

Метод повертає помилку з кодом **400**, якщо параметр `case` відсутній або порожній, 
та з кодом **404**, якщо інформацію про справу не знайдено.

  * `date` - дата і час засідання;

  * `court_room` - зала судових засідань;

## court.decision
Метод повертає судове рішення за його ідентифікатором.

##### Приклад запиту:
https://clarity-project.info/api/court.decision/100000001?key=xxx,
де **100000001** - ідентифікатор рішення (`doc_id`).

Метод повертає помилку з кодом **404**, якщо рішення не знайдено, 
та з кодом **451**, якщо доступ до рішення обмежено.

##### Приклад відповіді:
```json
{
  "result": {
    "decision": {
      "doc_id": 100000001,
      "cause_num": "000/0000/23",
      "court_code": "0001",
      "court_name": "Прикладний районний суд м. Києва",
      "category_code": "40000",
      "category_name": "Спори про стягнення заборгованості",
      "judgment_code": "5",
      "judgment_form": "Ухвала",
      "justice_kind": "1",
      "justice_kind_name": "Цивільне",
      "judge": "Приклад П. І.",
      "status": 1,
      "is_downloaded": true,
      "adjudication_date": "2023-04-10",
      "receipt_date": "2023-04-12",
      "date_publ": "2023-04-13"
    },
    "text": "<p>Справа № 000/0000/23</p>\n<p>УХВАЛА</p>\n<p>ІМЕНЕМ УКРАЇНИ</p>\n<p>...</p>",
    "participants": [
      {
        "name": "ПРИКЛАД ПЕТРО ІВАНОВИЧ",
        "raw_name": null,
        "role": "main_judge",
        "status": "головуючий суддя",
        "type": "person"
      },
      {
        "name": "ПРИКЛАДНИЙ ІВАН ПЕТРОВИЧ",
        "raw_name": null,
        "role": "participant",
        "status": "відповідач",
        "type": "person"
      }
    ]
  },
  "stats": { }
}
```

##### Опис полів:
* `decision` - [судове рішення](#судове-рішення);
* `text` - текст рішення у форматі HTML, `null` - якщо текст відсутній;
* `participants` - список [учасників справи](#учасник-справи);

## edr.info/court-cases
Метод повертає судові справи, учасником яких є юридична особа. 
Справи шукаються за назвою, скороченою назвою та кодом ЄДРПОУ.

##### Параметри:
* **page** - сторінка результатів, за замовчуванням перша;

##### Приклад запиту:
https://clarity-project.info/api/edr.info/00000000/court-cases?page=1&key=xxx,
де **00000000** - код ЄДРПОУ.

Метод повертає по 25 справ на сторінку.

Метод повертає помилку з кодом **404**, якщо компанію не знайдено, 
та з кодом **451**, якщо доступ до даних компанії обмежено.

##### Приклад відповіді:
```json
{
  "result": {
    "items": [
      {
        "case_number": "000/0000/23",
        "name": "ТОВ \"ПРИКЛАД\"",
        "status": "позивач",
        "state": {
          "case_number": "000/0000/23",
          "court_name": "Прикладний районний суд м. Києва",
          "case_proc": "2/000/0000/23",
          "registration_date": "2023-03-01",
          "stage_date": "2023-04-10",
          "stage_name": "Призначено до судового розгляду",
          "cause_result": "",
          "cause_dep": "",
          "type": "позовна заява",
          "description": "про стягнення заборгованості"
        }
      },
      {
        "case_number": "000/0001/22",
        "name": "ТОВ \"ПРИКЛАД\"",
        "status": "відповідач",
        "state": {
          "case_number": null,
          "court_name": "Прикладний районний суд м. Києва",
          "case_proc": null,
          "registration_date": null,
          "stage_date": null,
          "stage_name": null,
          "cause_result": null,
          "cause_dep": null,
          "type": null,
          "description": "про визнання договору недійсним"
        }
      }
    ],
    "total": 2,
    "page": 1,
    "perPage": 25,
    "limit": 25,
    "offset": 0
  },
  "stats": { }
}
```

##### Опис полів:
* `items` - список судових справ:
  * `case_number` - номер справи;
  * `name` - ім'я або назва учасника справи;
  * `status` - процесуальний статус учасника в справі, наприклад «позивач» чи «відповідач»;
  * `state` - [стан розгляду справи](#стан-розгляду-справи), `null` - якщо відсутній. 
    Для частини справ заповнені лише поля `court_name` та `description`;
* поля пагінації описані в розділі [Пагінація](#пагінація);

## persons.info/court-cases
Метод повертає судові справи, учасником яких є фізична особа. 
Справи шукаються за ПІБ, тому у відповідь можуть потрапити справи повних тезок.

##### Параметри:
* **page** - сторінка результатів, за замовчуванням перша;

##### Приклад запиту:
https://clarity-project.info/api/persons.info/00000000000000000000000000000000/court-cases?page=1&key=xxx

Де:
* `00000000000000000000000000000000` - це ідентифікатор (`hash`) особи з методу 
  [persons.search](persons.search.md#personssearch), або її ПІБ.

Метод повертає по 25 справ на сторінку, формат відповіді такий самий, 
як у методу [edr.info/court-cases](#edrinfocourt-cases).

Метод повертає помилку з кодом **404**, якщо особу не знайдено.

## Судове рішення
* `doc_id` - ідентифікатор рішення, використовується в методі [court.decision](#courtdecision);
* `cause_num` - номер справи;
* `court_code`, `court_name` - код та назва суду;
* `category_code`, `category_name` - код та назва категорії справи;
* `judgment_code`, `judgment_form` - код та назва форми рішення (наприклад, «Ухвала»);
* `justice_kind`, `justice_kind_name` - код та назва форми судочинства (наприклад, «Цивільне»);
* `judge` - суддя;
* `status` - `0`, якщо текст рішення не був опублікований у формі відкритих даних, інакше `1`;
* `is_downloaded` - `true`, якщо текст рішення вже завантажено і його можна отримати 
  методом [court.decision](#courtdecision);
* `adjudication_date` - дата ухвалення рішення;
* `receipt_date` - дата надходження рішення;
* `date_publ` - дата оприлюднення рішення;

Дати повертаються у форматі `YYYY-MM-DD`, `null` - якщо відсутні.

## Стан розгляду справи
* `case_number` - номер справи;
* `court_name` - назва суду;
* `case_proc` - номер провадження;
* `registration_date` - дата надходження справи;
* `stage_date`, `stage_name` - дата та назва поточної стадії розгляду;
* `cause_result` - результат розгляду;
* `cause_dep` - значення з джерела без обробки;
* `type` - тип звернення;
* `description` - предмет позову або опис справи;

Відсутні значення повертаються як `null` або порожній рядок.

## Учасник справи
* `name` - ім'я або назва учасника;
* `raw_name` - ім'я у вихідному написанні з джерела, може бути `null`;
* `role` - роль: `main_judge` - головуючий суддя, `judge` - суддя, `participant` - учасник справи;
* `status` - текстовий опис ролі, наприклад «головуючий суддя» чи «відповідач»;
* `type` - тип учасника, `person` - фізична особа;

## Пагінація
* `items` - записи поточної сторінки;
* `total` - загальна кількість записів;
* `page` - номер поточної сторінки;
* `perPage`, `limit` - кількість записів на сторінці;
* `offset` - зсув першого запису сторінки;
